## ⚙️ Nexus OS — what's in the build

My portfolio isn't a page, it's a small operating system. [Boot it →](https://fellow3-1.github.io/Fellow3-1/)

```text
$ neofetch
  OS........ Nexus OS 3.1 LTS (phosphor terminal edition)
  Kernel.... house-android 6.1.0-nbo
  Uptime.... 12+ years in production
  Shell..... zsh + neovim (btw)
  Stack..... React · TypeScript · Go · Docker · Kubernetes
  Status.... ● OPEN FOR WORK — Nairobi, UTC+3
```

- ⌘ **Command palette** — hit `⌘K` / `Ctrl+K` (or `/`) anywhere to jump to any section, copy my email, or grab my résumé.
- ⌘ **Real terminal** — the contact section runs an interactive shell. Type `help`, `neofetch`, `stack`, `projects`… history and tab-completion included.
- ⌘ **Kernel boot** — a 1.4s skippable boot sequence (reduced-motion users skip straight in).
- ⌘ **Contribution matrix** — a living GitHub-style commit graph with a serpent eating the year.
- ⌘ **Zero-bleed UI** — `100svh` hero, scroll-locked overflow, 44px touch targets, `hover`-gated effects, full `prefers-reduced-motion` support.
